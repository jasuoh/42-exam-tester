Écrivez une fonction qui renvoie le PPCM (plus petit commun
multiple, LCM en anglais) de deux unsigned int : le plus petit
entier positif divisible par les deux. Si l'un des deux vaut 0, le
PPCM vaut 0.

Exemples :
    lcm(4, 6)  -> 12
    lcm(21, 6) -> 42
    lcm(0, 5)  -> 0

    unsigned int lcm(unsigned int a, unsigned int b);
