Écrivez une fonction qui renvoie les éléments qui apparaissent
exactement une fois dans une liste, dans leur ordre d'origine. Les
éléments qui se répètent sont entièrement supprimés, y compris leur
première occurrence.

    def unique_elements(lst: list[int]) -> list[int]:

Exemples :
    unique_elements([1,2,2,3,4,4,5]) -> [1, 3, 5]
    unique_elements([1,1,1])         -> []
    unique_elements([])              -> []
