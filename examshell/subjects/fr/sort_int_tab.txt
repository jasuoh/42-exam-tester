Écrivez une fonction qui trie (sur place) un tableau d'int de `size`
éléments, par ordre croissant. Les doublons doivent être conservés.

Exemples :
    sort_int_tab([5,3,1,4,2], 5) -> tab becomes [1,2,3,4,5]
    sort_int_tab([], 0)          -> tab stays []

    void sort_int_tab(int *tab, unsigned int size);
