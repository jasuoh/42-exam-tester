Écrivez une fonction qui renvoie la différence maximale entre deux
éléments SUCCESSIFS une fois le tableau trié par ordre croissant.
Avec moins de 2 éléments, renvoyez 0. Le tableau reçu ne doit pas
être modifié — triez une copie.

Exemples :
    max_gap([1,5,3,19,18,25], 6) -> 13  (sorted: 1,3,5,18,19,25)
    max_gap([3,3], 2)            -> 0

    int max_gap(int *arr, unsigned int size);
