Vous disposez d'une quantité illimitée de pièces de chaque valeur
présente dans `coins`. Renvoyez le nombre minimal de pièces
nécessaires pour obtenir exactement `amount`, ou -1 si c'est
impossible. amount = 0 nécessite 0 pièce.

    def coin_change(coins: list[int], amount: int) -> int:

Exemples :
    coin_change([1,2,5], 11) -> 3   # 5+5+1
    coin_change([2], 3)       -> -1
    coin_change([1], 0)       -> 0
