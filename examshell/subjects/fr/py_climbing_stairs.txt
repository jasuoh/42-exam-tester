Vous montez un escalier de n marches. À chaque mouvement, vous
pouvez monter 1 ou 2 marches. Renvoyez le nombre de façons
distinctes d'atteindre le sommet. Pour n = 0, il y a exactement une
façon (ne rien faire).

    def climbing_stairs(n: int) -> int:

Exemples :
    climbing_stairs(2) -> 2   # 1+1, 2
    climbing_stairs(3) -> 3   # 1+1+1, 1+2, 2+1
    climbing_stairs(0) -> 1
