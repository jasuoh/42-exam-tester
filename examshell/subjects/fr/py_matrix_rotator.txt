Écrivez une fonction qui fait pivoter une matrice de 90 degrés dans
le sens des aiguilles d'une montre. La matrice est rectangulaire ; le
résultat peut avoir des dimensions différentes de l'entrée (une
matrice RxC devient une matrice CxR).

    def matrix_rotator(matrix: list[list[int]]) -> list[list[int]]:

Exemples :
    matrix_rotator([[1,2],[3,4]])     -> [[3,1],[4,2]]
    matrix_rotator([[1,2,3],[4,5,6]]) -> [[4,1],[5,2],[6,3]]
    matrix_rotator([])                -> []
