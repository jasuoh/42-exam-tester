Écrivez une fonction qui supprime de la liste chaque élément dont
les données sont « égales » à `data_ref`, selon `cmp` (qui renvoie 0
quand ses deux arguments void* sont égaux). Vous devez utiliser le
type t_list décrit dans ft_list.h (fourni).

Exemples :
    ft_list_remove_if([1,2,3,2,1], &2, cmp) -> list becomes [1,3,1]
    ft_list_remove_if([5,5,5], &5, cmp)      -> list becomes []

    void ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)(void *, void *));
