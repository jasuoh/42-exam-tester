Écrivez une fonction qui renvoie 1 si les chiffres décimaux de `n` se
lisent de la même façon dans les deux sens, 0 sinon. Les nombres
négatifs ne sont jamais des palindromes.

Exemples :
    is_palindrome_num(121)  -> 1
    is_palindrome_num(-121) -> 0
    is_palindrome_num(10)   -> 0

    int is_palindrome_num(int n);
