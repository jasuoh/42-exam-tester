Dispones de una cantidad ilimitada de cada valor de moneda de
`coins`. Devuelve el número mínimo de monedas necesario para formar
exactamente `amount`, o -1 si no es posible. amount = 0 necesita 0
monedas.

    def coin_change(coins: list[int], amount: int) -> int:

Ejemplos:
    coin_change([1,2,5], 11) -> 3   # 5+5+1
    coin_change([2], 3)       -> -1
    coin_change([1], 0)       -> 0
