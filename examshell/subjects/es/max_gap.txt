Escribe una función que devuelva la diferencia máxima entre dos
elementos SUCESIVOS una vez ordenado el array en orden ascendente.
Con menos de 2 elementos devuelve 0. El array recibido no debe
modificarse: ordena una copia.

Ejemplos:
    max_gap([1,5,3,19,18,25], 6) -> 13  (sorted: 1,3,5,18,19,25)
    max_gap([3,3], 2)            -> 0

    int max_gap(int *arr, unsigned int size);
