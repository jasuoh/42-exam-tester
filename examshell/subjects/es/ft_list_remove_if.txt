Escribe una función que elimine de la lista todos los elementos
cuyos datos sean "iguales" a `data_ref`, según `cmp` (que devuelve
0 cuando sus dos argumentos void* son iguales). Debes usar el tipo
t_list descrito en ft_list.h (proporcionado).

Ejemplos:
    ft_list_remove_if([1,2,3,2,1], &2, cmp) -> list becomes [1,3,1]
    ft_list_remove_if([5,5,5], &5, cmp)      -> list becomes []

    void ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)(void *, void *));
