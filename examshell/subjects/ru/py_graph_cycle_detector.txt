Напишите функцию, которая определяет, содержит ли ОРИЕНТИРОВАННЫЙ
граф хотя бы один цикл.

    def graph_cycle_detector(graph: dict[int, list[int]]) -> bool:

· graph — это список смежности: каждый ключ — идентификатор узла,
  каждое значение — список узлов, на которые он указывает.
· Верните True, если граф содержит цикл, и False, если он ацикличен,
  в том числе для пустого графа.
· Граф может состоять из нескольких несвязанных компонент; цикл в
  любой из них засчитывается.
· Ребро, указывающее на узел, который сам не является ключом
  словаря, никуда не ведёт и не входит ни в какой цикл.

(В некоторых кампусах эта функция называется
py_graph_cycle_detector — требуемое поведение то же самое.)

Примеры:
    graph_cycle_detector({0: [1], 1: [2], 2: [0]}) -> True
    graph_cycle_detector({0: [1], 1: [2], 2: []})  -> False
    graph_cycle_detector({})                       -> False
