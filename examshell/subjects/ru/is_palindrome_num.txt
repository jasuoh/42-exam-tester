Напишите функцию, которая возвращает 1, если десятичные цифры `n`
читаются одинаково слева направо и справа налево, иначе 0.
Отрицательные числа никогда не являются палиндромами.

Примеры:
    is_palindrome_num(121)  -> 1
    is_palindrome_num(-121) -> 0
    is_palindrome_num(10)   -> 0

    int is_palindrome_num(int n);
