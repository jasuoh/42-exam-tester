для чисел, кратных 5, "FizzBuzz" для чисел, кратных обоим, иначе само
число в виде строки. При n = 0 возвращается пустой список.

    def fizzbuzz_list(n: int) -> list[str]:

    fizzbuzz_list(5)  -> ["1", "2", "Fizz", "4", "Buzz"]
