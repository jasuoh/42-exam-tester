Напишите функцию, которая возвращает НОК (наименьшее общее кратное,
LCM) двух unsigned int: наименьшее положительное целое число,
делящееся на оба. Если хотя бы одно из них равно 0, НОК равен 0.

Примеры:
    lcm(4, 6)  -> 12
    lcm(21, 6) -> 42
    lcm(0, 5)  -> 0

    unsigned int lcm(unsigned int a, unsigned int b);
