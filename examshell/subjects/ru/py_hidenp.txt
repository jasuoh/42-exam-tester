Напишите функцию, которая проверяет, является ли 'small'
подпоследовательностью 'big'. Подпоследовательность означает, что все
символы 'small' встречаются в 'big' в том же порядке, но не
обязательно подряд. С учётом регистра.

    def hidenp(small: str, big: str) -> bool:

Примеры:
    hidenp("abc", "a1b2c3") -> True
    hidenp("ace", "abcde")  -> True
    hidenp("aec", "abcde")  -> False
    hidenp("", "abc")       -> True
