Напишите ПРОГРАММУ, которая принимает одну или несколько строк и для
каждой из них делает ПЕРВУЮ букву каждого слова заглавной, а
остальные — строчными, выводя результат для каждого аргумента на
отдельной строке. Если аргументов нет, выведите только символ новой
строки.

Примеры:
    ./str_capitalizer "a first test" -> A First Test

    int main(int argc, char **argv);
