Напишите ПРОГРАММУ, которая принимает одну или несколько строк и для
каждой из них делает ПОСЛЕДНЮЮ букву каждого слова заглавной, а
остальные — строчными (слово из одной буквы становится заглавным),
выводя результат для каждого аргумента на отдельной строке. Если
аргументов нет, выведите только символ новой строки.

Примеры:
    ./rstr_capitalizer "a first test" -> a firsT tesT

    int main(int argc, char **argv);
