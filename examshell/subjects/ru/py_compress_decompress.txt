Напишите ДВЕ функции: компрессор с кодированием длин серий (RLE) и
его точную обратную функцию.

    def compress(s: str) -> str:
    def decompress(s: str) -> str:

compress:
  · Сожмите каждую серию повторяющихся символов в этот символ, за
    которым следует количество его повторений.
  · Серия ровно из ОДНОГО символа не получает числа: "abc" остаётся
    "abc" и не превращается в "a1b1c1".
  · Пустая строка сжимается в пустую строку.
  · Входные данные содержат только буквы.

decompress:
  · Разверните сжатую строку обратно в исходный вид.
  · Количество может состоять из нескольких цифр: "a12" — это
    двенадцать букв a.
  · Символ, после которого нет цифр, считается одним.

Оцениваются обе функции, поэтому обе должны быть определены в вашем
файле.

Примеры:
    compress("aabcccccaaa")   -> "a2bc5a3"
    decompress("a2bc5a3")     -> "aabcccccaaa"
    compress("")              -> ""
    decompress("a12")         -> "aaaaaaaaaaaa"
