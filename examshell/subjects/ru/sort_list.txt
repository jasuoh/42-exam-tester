Напишите функцию, которая сортирует список, переданный в качестве
параметра, используя указатель на функцию `cmp` для выбора порядка,
и возвращает указатель на первый элемент отсортированного списка.
Дубликаты должны сохраняться. `cmp` возвращает значение != 0, когда
два её аргумента уже стоят в правильном порядке, и 0 в противном
случае; например, такая функция сортирует по возрастанию:

    int ascending(int a, int b) { return (a <= b); }

Вы должны использовать тип t_list, описанный в list.h
(предоставляется).

Примеры:
    sort_list([5,3,1,4,2], ascending) -> [1,2,3,4,5]
    sort_list([], ascending)           -> []

    t_list *sort_list(t_list *lst, int (*cmp)(int, int));
