Напишите функцию, которая возвращает самый частый символ в строке (с
учётом регистра). Если у нескольких символов одинаковое наибольшее
количество, верните тот из них, который первым достигает этого
количества при просмотре строки слева направо. Для пустой строки
возвращается "".

    def char_frequency(text: str) -> str:

Примеры:
    char_frequency("aabbb")  -> "b"
    char_frequency("aabb")   -> "a"
    char_frequency("")       -> ""
