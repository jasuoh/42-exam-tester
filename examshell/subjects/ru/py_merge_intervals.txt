Напишите функцию, которая объединяет все пересекающиеся интервалы.
Каждый интервал — это [start, end], где start <= end. Два интервала
пересекаются, если один начинается не позже, чем заканчивается
другой. Верните объединённые интервалы, отсортированные по началу.

    def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:

Примеры:
    merge_intervals([[1,3],[2,6],[8,10],[15,18]])
        -> [[1,6],[8,10],[15,18]]
    merge_intervals([[1,4],[4,5]]) -> [[1,5]]
    merge_intervals([])            -> []
