Напишите функцию, которая возвращает максимальную разность между
двумя СОСЕДНИМИ элементами после сортировки массива по возрастанию.
Если элементов меньше 2, возвращается 0. Исходный массив изменять
нельзя — сортируйте копию.

Примеры:
    max_gap([1,5,3,19,18,25], 6) -> 13  (sorted: 1,3,5,18,19,25)
    max_gap([3,3], 2)            -> 0

    int max_gap(int *arr, unsigned int size);
