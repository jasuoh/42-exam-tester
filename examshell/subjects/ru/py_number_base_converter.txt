Напишите функцию, которая переводит число из одной системы счисления
в другую. Оба основания — от 2 до 36 включительно. Цифры — это 0-9,
затем A-Z для значений 10-35; ВЫВОД всегда использует заглавные
буквы, ВВОД принимает буквы в любом регистре. Допускается ведущий
'-', и ничего больше: ни '+', ни пробелов, ни подчёркиваний.

Верните строку "ERROR" для любых некорректных данных: основание вне
2..36, пустое число или цифра, которой нет в системе `from_base`.

    def number_base_converter(number: str, from_base: int, to_base: int) -> str:

Примеры:
    number_base_converter("1010", 2, 10) -> "10"
    number_base_converter("FF", 16, 10)  -> "255"
    number_base_converter("ff", 16, 10)  -> "255"
    number_base_converter("255", 10, 16) -> "FF"
    number_base_converter("-1010", 2, 10)-> "-10"
    number_base_converter("123", 1, 10)  -> "ERROR"
    number_base_converter("G", 16, 10)   -> "ERROR"
