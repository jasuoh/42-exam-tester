Напишите функцию, которая возвращает количество элементов в
переданном ей связном списке. Вы должны использовать тип t_list,
описанный в list.h (предоставляется): узел содержит int `data` и
указатель `next` на следующий узел (NULL в конце списка).

Примеры:
    ft_list_size([1,2,3]) -> 3
    ft_list_size([])       -> 0

    int ft_list_size(t_list *begin_list);
