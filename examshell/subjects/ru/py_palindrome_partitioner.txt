Дана строка. Найдите МИНИМАЛЬНОЕ количество разрезов, необходимое,
чтобы разбить её так, чтобы каждая получившаяся часть была
палиндромом.

    def palindrome_partitioner(s: str) -> int:

· Верните количество разрезов в виде целого числа.
· Строке, которая уже является палиндромом, нужно 0 разрезов.
· Строке из одного символа нужно 0 разрезов, как и пустой строке.

Примеры:
    palindrome_partitioner("aab") -> 1     # "aa" | "b"
    palindrome_partitioner("aba") -> 0     # already a palindrome
    palindrome_partitioner("abc") -> 2     # "a" | "b" | "c"
