Напишите функцию, которая удаляет из списка каждый элемент, данные
которого "равны" `data_ref` согласно `cmp` (она возвращает 0, когда
два её аргумента void* равны). Вы должны использовать тип t_list,
описанный в ft_list.h (предоставляется).

Примеры:
    ft_list_remove_if([1,2,3,2,1], &2, cmp) -> list becomes [1,3,1]
    ft_list_remove_if([5,5,5], &5, cmp)      -> list becomes []

    void ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)(void *, void *));
