Напишите функцию, которая подсчитывает допустимые пары соседних цифр
в строке. Допустимая пара — это две соседние цифры, где вторая ровно
на единицу больше первой. 9, за которой следует 0, НЕ является
допустимой парой.

    def pattern_tracker(text: str) -> int:

Примеры:
    pattern_tracker("123")       -> 2
    pattern_tracker("12a34")     -> 2
    pattern_tracker("987654321") -> 0
    pattern_tracker("90")        -> 0
