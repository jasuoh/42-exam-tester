Напишите функцию, которая сортирует список строк по нескольким
критериям:
  1. Первичный  : по длине (сначала самые короткие)
  2. Вторичный  : в порядке ASCII, буквы сравниваются без учёта
                  регистра
  3. Третичный  : по количеству гласных (по возрастанию)
  4. Равные строки сохраняют исходный порядок (стабильная
     сортировка).

    def cryptic_sorter(strings: list[str]) -> list[str]:

Примеры:
    cryptic_sorter(["apple","cat","banana","dog","elephant"])
        -> ["cat","dog","apple","banana","elephant"]
    cryptic_sorter(["aaa","bbb","AAA","BBB"]) -> ["aaa","AAA","bbb","BBB"]
    cryptic_sorter([]) -> []
