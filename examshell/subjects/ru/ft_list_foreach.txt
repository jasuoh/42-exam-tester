Напишите функцию, которая проходит по связному списку и применяет
указатель на функцию `f` к данным каждого элемента, вызывая её как
`(*f)(node->data)`. Вы должны использовать тип t_list, описанный в
ft_list.h (предоставляется): узел содержит `void *data` и указатель
`next`.

Тестер проверяет это, суммируя значение (int) каждого элемента при
обходе вашей функцией: правильный foreach посещает каждый узел ровно
один раз, по порядку.

Примеры:
    ft_list_foreach([1,2,3], f) -> f is called with 1, then 2, then 3

    void ft_list_foreach(t_list *begin_list, void (*f)(void *));
