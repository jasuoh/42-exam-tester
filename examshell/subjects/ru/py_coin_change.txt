У вас есть неограниченный запас монет каждого номинала из `coins`.
Верните минимальное количество монет, необходимое, чтобы набрать
ровно `amount`, или -1, если это невозможно. Для amount = 0 нужно 0
монет.

    def coin_change(coins: list[int], amount: int) -> int:

Примеры:
    coin_change([1,2,5], 11) -> 3   # 5+5+1
    coin_change([2], 3)       -> -1
    coin_change([1], 0)       -> 0
