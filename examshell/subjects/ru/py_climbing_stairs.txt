Вы поднимаетесь по лестнице из n ступенек. За один ход можно
подняться на 1 или на 2 ступеньки. Верните количество различных
способов добраться до верха. При n = 0 существует ровно один способ
(ничего не делать).

    def climbing_stairs(n: int) -> int:

Примеры:
    climbing_stairs(2) -> 2   # 1+1, 2
    climbing_stairs(3) -> 3   # 1+1+1, 1+2, 2+1
    climbing_stairs(0) -> 1
