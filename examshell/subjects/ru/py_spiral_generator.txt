Напишите функцию, которая строит матрицу n x n, заполненную числами
1..n² по спирали по часовой стрелке.

    def generate_spiral(n: int) -> list[list[int]]:

Спираль начинается в левой верхней клетке (0, 0) и идёт вправо, затем
вниз, затем влево, затем вверх, закручиваясь к центру. При n, равном
0 или меньше, возвращается пустой список.

Примеры:
    generate_spiral(3) -> [[1, 2, 3], [8, 9, 4], [7, 6, 5]]
    generate_spiral(1) -> [[1]]
    generate_spiral(0) -> []
