в строке. Правильно — значит, у каждой открывающей скобки есть
соответствующая закрывающая скобка в правильном порядке. Допустимые
скобки: (), [], {}. Остальные символы игнорируются.

Примеры:
    bracket_validator("()[]{}")       -> True
    bracket_validator("([)]")         -> False
    bracket_validator("hello(world)") -> True
    bracket_validator("")             -> True
