Напишите функцию, которая определяет, является ли arr2 циклическим
сдвигом (ротацией) arr1. Ротация циклически сдвигает все элементы,
сохраняя их относительный порядок: [4,5,1,2,3] — ротация [1,2,3,4,5],
а [3,2,1] — не ротация [1,2,3].

    def array_rotation_detector(arr1: list, arr2: list) -> bool:

Верните True, если arr2 является допустимой ротацией arr1, иначе
False (в том числе когда длины различаются). Два пустых списка
считаются допустимой ротацией.

Примеры:
    array_rotation_detector([1,2,3,4,5], [4,5,1,2,3]) -> True
    array_rotation_detector([1,2,3,4,5], [5,1,2,3,4]) -> True
    array_rotation_detector([1,2,3], [3,2,1])         -> False
    array_rotation_detector([1,2], [1,2,3])           -> False
    array_rotation_detector([], [])                   -> True
