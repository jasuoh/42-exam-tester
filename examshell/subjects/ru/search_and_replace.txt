Напишите ПРОГРАММУ с именем search_and_replace, которая принимает 3
аргумента: строку, один символ для поиска и один символ для замены.
Каждое вхождение первого символа 2-го аргумента в строке заменяется
первым символом 3-го аргумента; результат выводится, а затем символ
новой строки. Если argc != 4, выведите только символ новой строки.

Примеры:
    ./search_and_replace "hello world" "o" "0" -> hell0 w0rld
    ./search_and_replace "banana" "a" "e"        -> benene

    int main(int argc, char **argv);
