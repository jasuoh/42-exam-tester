Напишите функцию, которая находит два РАЗНЫХ элемента списка, сумма
которых равна target, и возвращает их индексы [i, j], где i < j. Если
подходят несколько пар, верните ту, что найдена первой при переборе i
по возрастанию, затем j по возрастанию. Если ни одна пара не
подходит, верните [].

    def two_sum_indices(lst: list[int], target: int) -> list[int]:

Примеры:
    two_sum_indices([2,7,11,15], 9) -> [0, 1]
    two_sum_indices([3,2,4], 6)     -> [1, 2]
    two_sum_indices([1,2,3], 100)   -> []
