Напишите функцию, которая выделяет с помощью malloc массив int,
заполненный всеми последовательными значениями от `start` до `end`
включительно (по возрастанию, даже если start > end — это задача
ft_rrange), и возвращает указатель на него.

Примеры:
    ft_range(1, 3)  -> [1, 2, 3]
    ft_range(-1, 2) -> [-1, 0, 1, 2]
    ft_range(0, 0)  -> [0]

    int *ft_range(int start, int end);
