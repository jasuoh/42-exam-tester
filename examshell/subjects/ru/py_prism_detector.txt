Напишите функцию, которая находит все вхождения шаблона в двумерной
сетке символов во всех 8 направлениях.

    def prism_detector(grid: list[str], pattern: str) -> list[tuple]:

Направления (dx, dy) и код, который сообщается для каждого из них, в
таком порядке:

    (1, 0)    "H"     по горизонтали, вправо
    (-1, 0)   "H-"    по горизонтали, влево
    (0, 1)    "V"     по вертикали, вниз
    (0, -1)   "V-"    по вертикали, вверх
    (1, 1)    "D1"    по диагонали, вниз-вправо
    (-1, -1)  "D1-"   по диагонали, вверх-влево
    (-1, 1)   "D2"    по диагонали, вверх-вправо
    (1, -1)   "D2-"   по диагонали, вниз-влево

· Верните список кортежей (x, y, direction_code), по одному на каждое
  совпадение, где x — столбец, а y — строка ПЕРВОГО символа шаблона.
· Просматривайте сетку строка за строкой, слева направо, и пробуйте
  направления в указанном выше порядке.
· Верните [], если сетка или шаблон пусты.

Примеры:
    prism_detector(["CAT", "A..", "T.."], "CAT")
        -> [(0, 0, "H"), (0, 0, "V")]
    prism_detector([], "CAT")   -> []
    prism_detector(["CAT"], "") -> []
